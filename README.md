# Ionic y Angular — ejemplos de curso

Colección docente con una aplicación de pestañas, una introducción a Angular y una aplicación de noticias.

## Scope

Los manifests inspeccionados usan Angular 13 en los ejemplos Ionic y Angular 14 en el ejemplo Angular. El nombre del repositorio no implica que todo el código use Angular 15.

## Technology / Material

Ionic 6 · Angular 13/14 según ejemplo · TypeScript · Capacitor

## Getting started / Reproducibility

Entra en la carpeta del ejemplo, revisa su `package.json`, instala sus dependencias y usa su script `npm start`. Cada ejemplo tiene su propio entorno.
